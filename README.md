# Operationalized Integrity Principles (OIP) 
This repository is a **GitHub mirror and working distribution** of the archived Zenodo release for OIP
The canonical archival citation remains the Zenodo record for OIP v1.1 while newer schema updates are published here via GitHub releases 
**Canonical citation record (DOI):** https://doi.org/10.5281/zenodo.18371018  
**GitHub release tag:** v1.1 

## What this contains 
- Academic paper (PDF)
- OIP Handbook (PDF)
- OIP-Core (text/PDF)
- OIP-JSON schemas (Standard + Persistent - current schemas are v1.2)
- OIP-TF testing framework artefacts (schema and self-test - current schema is v1.2)
- README.pdf (mirror of zenodo archive)

## Versioning 
- `main` tracks the latest stable release (currently **v1.2**).
- The v1.1 schemas are now **deprecated** and retained for historical reference via the v1.1 release/tag
- `v1.0` is **deprecated** and retained for historical reference via the `v1.0` release/tag.
